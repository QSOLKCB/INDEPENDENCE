# Roadmap

v0.1 — Working declaration (this PR)
- High-contrast responsive GitHub Pages site.
- Deterministic cellular automaton and local self-test button.
- Labelled synthetic dependency graph experiment.
- Offline Python standard-library audit, adversarial fixtures, and documentation.

v0.2 — Public evidence ledger (implemented in this PR)
- Paginated public-only repository inventory, curated category correlation, and scoped Git tree filename indicators.
- Snapshot receipt, reproducible offline regression fixtures and explicit unknown handling.
- Static browser search/filter; no browser-side GitHub API calls.
- Import/dependency graph resolution and immutable historical archive are future work.

v0.3 — Dependency Tribunal (implemented)
- First-party direct DOM and illustrative keyed-reconciliation adapters, identical fixture and correctness checks.
- Explicit user-initiated paired browser measurements: alternating order, warmups, medians, bootstrap percentile intervals.
- Source byte measurements, SHA-256 receipt downloads, Python stdlib integrity verifier and adversarial tests.
- No claims about production frameworks, security, deployment footprint, or cross-machine superiority.
- Real framework candidates, ergonomics, patching and build-size analyses require future version-pinned third-party fixtures.

v0.4 — The Gremlin Museum (implemented in this PR)
- Five isolated browser specimens: remote side-effect import audit bypass, checkout ancestry false positive, SHA format confusion, JSON finite-number drift and HTML output encoding.
- Clearly distinguish three historical review findings from two generic illustrative security classes.
- Fixed inputs, bounded reproductions, corrected behaviour and deterministic assertions; no real exploits.
- Exportable SHA-256 receipts, Python standard-library verifier and adversarial offline tests.
- Same-origin static GitHub Pages museum, without external dependencies or browser API calls.

v0.5 — The Gremlin Breeding Laboratory (implemented in this PR)
- Fifteen fixed pure-function mutants over five targets; no dynamic source modification or execution.
- Seeded ordering, full baseline oracles and a demonstrated divergence witness per mutant.
- Smoke versus extended fixture suites with killed/survived outcomes and a scoped mutation score.
- SHA-256 local receipt export and Python stdlib verifier with independently encoded expected outcomes.
- No repository-wide mutation coverage, external vulnerability scanning, or real-world attack claims.

v0.6 — The Secret Source: AI–Human GitHub Workflow (implemented in this PR)
- Public, human-owned eight-stage AI + GitHub engineering loop; show evidence and human/AI division of responsibility.
- Interactive drift-prevention checklist; self-assessment only, never a fabricated verification or automatic approval.
- Local, plain-text bounded prompt composer with explicit negative scope, invariants, test requirements, latest HEAD and stop conditions.
- Real PR #1–#5 case studies; no invented AI accuracy metrics, comparison benchmarks or claims of infinite capability.
- First-party static HTML/CSS/JavaScript only, offline Python tests, manual Pages deployment; no third-party packages, telemetry or LLM API calls.

v0.7 — Proof Contracts (implemented in this PR)
- Eight versioned machine-readable proof obligations with actual source targets, priority, explicit NOT_PROVED formal status, baseline v0.6.0 SHA.
- Bounded-exhaustive/finite JavaScript checks with independent oracles, plus a reproducible mutable-fingerprint counterexample.
- Fail-closed Python registry check and offline receipt verification, negative/adversarial regression tests, local-only browser UI.
- No Lean or SPARK proof or execution attestation is claimed.

v0.8 — Property generation and counterexample minimization (planned)
- Deterministic generative inputs, fault injection and cross-language fixtures; resolve typed-array ownership contract.

v0.9 — Lean 4 + SPARK Ada proof laboratory (planned)
- Human-reviewed specification, Lean kernel-checked theorems, SPARK reference and GNATprove obligations, documented semantic bridge.

v1.0 — Real-browser and deployment verification (planned)
- Cross-browser journeys, CSP, accessibility, fault handling and deploy artifact checks.

v1.1.0 — Zenodo formalization of repository (planned)
- Exact tagged sources, executable proof artefacts and logs, assumptions, partial gaps, SHA manifest and transparent research report.

Each phase requires deterministic tests and a documented limitation statement.
