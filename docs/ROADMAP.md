# Roadmap

v0.1 — Working declaration (this PR)
- High-contrast responsive GitHub Pages site.
- Deterministic cellular automaton and local self-test button.
- Labelled synthetic dependency graph experiment.
- Offline Python standard-library audit, adversarial fixtures, and documentation.

v0.2 — Public evidence ledger (implemented in this PR)
- Paginated public-only repository inventory, curated category correlation, and scoped Git tree filename indicators.
- Snapshot receipt, reproducible offline regression fixtures and explicit unknown handling.
- Static browser search/filter; no browser-side GitHub API calls.
- Import/dependency graph resolution and immutable historical archive are future work.

v0.3 — Dependency Tribunal (implemented)
- First-party direct DOM and illustrative keyed-reconciliation adapters, identical fixture and correctness checks.
- Explicit user-initiated paired browser measurements: alternating order, warmups, medians, bootstrap percentile intervals.
- Source byte measurements, SHA-256 receipt downloads, Python stdlib integrity verifier and adversarial tests.
- No claims about production frameworks, security, deployment footprint, or cross-machine superiority.
- Real framework candidates, ergonomics, patching and build-size analyses require future version-pinned third-party fixtures.

v0.4 — The Gremlin Museum (implemented in this PR)
- Five isolated browser specimens: remote side-effect import audit bypass, checkout ancestry false positive, SHA format confusion, JSON finite-number drift and HTML output encoding.
- Clearly distinguish three historical review findings from two generic illustrative security classes.
- Fixed inputs, bounded reproductions, corrected behaviour and deterministic assertions; no real exploits.
- Exportable SHA-256 receipts, Python standard-library verifier and adversarial offline tests.
- Same-origin static GitHub Pages museum, without external dependencies or browser API calls.

Each phase requires deterministic tests and a documented limitation statement.
