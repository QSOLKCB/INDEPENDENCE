# Roadmap

v0.1 — Working declaration (this PR)
- High-contrast responsive GitHub Pages site.
- Deterministic cellular automaton and local self-test button.
- Labelled synthetic dependency graph experiment.
- Offline Python standard-library audit, adversarial fixtures, and documentation.

v0.2 — Public evidence ledger
- Opt-in, rate-aware repository inventory with per-repo scope.
- Snapshot artifacts with verified counts, dependency classifications, SHA-256 digests, and run provenance.
- Separate self-reported figures from externally verifiable findings.

v0.3 — Comparative experiments
- Paired workloads, identical behavior and target hardware, warmup, repetitions, medians, confidence bounds.
- Disclose differences in ergonomics and security patching as well as distribution size.
- No invented results or unsupported one-size-fits-all claims.

v0.4 — Security research exhibits
- Authorized local toy examples and test fixtures of common classes of vulnerabilities.
- Minimized reproductions, proposed mitigations, responsible disclosure.
- No active exploitation of third-party hosts.

Each phase requires deterministic tests and a documented limitation statement.
